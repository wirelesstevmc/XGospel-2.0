Pandanet (also known as IGS, Internet Go Server) offers a specific game timing system known as Pandanet style which is also referred to as Canadian time. This is one of the primary timing options available for games on the server. 
Canadian Timing (Pandanet Style)

The Canadian time system is a type of byoyomi (sudden death extra time) and functions as follows: 
Main Time: Each player starts with a set amount of main thinking time. Your timer runs only when it is your turn.
Extra Time (Byoyomi): Once a player's main time runs out, they enter extra time. In this phase, a player is given a fixed amount of time to make a specific number of moves (e.g., 10 minutes to play 25 moves).
Time Restoration: If a player completes the required number of moves within the allotted time, their extra time clock is reset to the original value for the next set of moves. This process repeats.

Forfeiture: A player loses the game if they fail to make the required number of moves within the specified extra time. 

Other Game Types and Features
Pandanet offers various other game options and features:
Timing Systems: In addition to Canadian time, the server supports Japanese timing (multiple fixed-length periods of extra time) and Absolute timing (no extra time; loss when main time runs out).
Board Sizes: Players can choose different board sizes, including the standard 19x19 board, as well as 9x9 and possibly other variations.

Handicap Games: The server facilitates handicap games to balance players of different skill levels, automatically adjusting parameters like komi (points awarded to white).

Pair Go: Pandanet was the first network to offer the option of Pair Go, a game where two teams of two players compete.
Clients: You can access the server using official clients like GoPanda2 on PC, or the Pandanet (Go) app on Android and iOS.

Tournaments: The server hosts various international and professional tournaments, with games often broadcast live for observation.
